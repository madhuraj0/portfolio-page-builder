## Features

- **No Sign-Up & Privacy-First**: Starts instantly in your browser; drafts auto-save to `localStorage` with zero backend or tracking.
- **32+ Blocks**: Hero covers, photo galleries, before/after sliders, verse/poetry, social bars, hire me badges, maps, audio, and FAQs.
- **Ambient Video Hero**: Loop background videos (MP4/WebM) or photos with customizable darkness overlays.
- **Inter-Block Scroll Reveal**: Smooth fade-in-up animations powered by native `IntersectionObserver`.
- **Drag & Drop**: Reorder blocks with visual drop guides.
- **Undo / Redo**: Keyboard shortcuts (`Ctrl+Z` / `Ctrl+Y`) and instant delete undo snackbar.
- **Photo Picker**: Curated Unsplash presets or client-side compressed local uploads.
- **Typography & Themes**: Curated font pairings, custom Google fonts, dark/light modes, and custom accent colors.
- **Responsive Previews**: Desktop, tablet, and mobile canvas toggles plus new-tab live preview.
- **Self-Contained Export**: Download standalone HTML with embedded fonts and SEO metadata.

---

## Quick Start

1. **Add**: Click any block in the palette to insert it.
2. **Reorder**: Drag the `⠿` handle to arrange blocks.
3. **Edit**: Double-click any block to edit content and styles.
4. **Export**: Click **Export** to preview in a new tab or download `.html`.

## Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl` / `Cmd` + `Z` | Undo |
| `Ctrl` / `Cmd` + `Y` | Redo |
| `Double Click` | Edit block |
| `Drag Handle` (`⠿`) | Reorder block |

## Run Locally

```bash
git clone https://github.com/madhuraj0/portfolio-page-builder.git
cd portfolio-page-builder
python3 -m http.server 8000
```

Open `http://localhost:8000`.
